# Spec QA: Golden Ratio System

## Result

Approved for Sprint 0.

## Checks

- The spec is scoped to visual-system refinement rather than a redesign.
- It preserves content, route order, artifact imagery, and the Next.js
  foundation.
- It names the exact token categories that should become phi-governed.
- It keeps readability and curator review as explicit acceptance checks.
- It excludes component extraction and new exhibit work.

## Risks To Watch

- ratio-derived values could make mobile spacing too loose if applied without
  review
- replacing every number mechanically could make the CSS harder to understand
- image frames must still fit the artifact photographs and renders
- the topbar must remain usable on narrow screens
