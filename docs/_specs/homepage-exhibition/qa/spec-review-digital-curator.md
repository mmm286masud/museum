# Spec QA: Digital Curator Design Application

## Result

Approved.

## Checks

- The design application stays inside the existing homepage workstream
- The imported design language is treated as a museum-specific adaptation, not
  as a literal copy of the stitched demo pages
- The required handheld chronology remains the primary content surface
- The refined design still supports Swiss discipline, scarcity framing, and the
  Explorer archetype

## Risks

- The stitched examples use placeholder branding that could dilute the museum identity
- External example image URLs must not become hidden dependencies
- Large design changes can make durable repository docs stale if they are not updated together

## Guardrails

- preserve the approved device list and chronology
- replace placeholder brand language with museum-specific language
- keep the live implementation local and self-contained
