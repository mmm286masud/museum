# Exhibit Package: Nintendo Game Boy DMG-01

## Status

Implemented as the featured artifact in the entrance hall homepage.

## Required Fields

### Title

Nintendo Game Boy DMG-01

### Release Year

1989

### Historical Context

The device succeeded by making disciplined compromises around battery life,
durability, cost, and public portability.

### Key Features

- reflective monochrome screen
- cartridge-based game ownership
- travel-viable battery performance

### Cultural Impact

It normalized portable play in everyday spaces such as school commutes, family
trips, and waiting rooms.

### Visual Artifact

Local SVG illustration at `assets/game-boy-dmg.svg`

### Narrative Placard

The device taught players to expect games as something they could carry, not
just visit in a living room or arcade.

### Scarcity Note

Intact early units with clean screens and working battery contacts are harder
to preserve over time, which changes how the artifact is read today.
