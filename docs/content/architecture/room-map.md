# Room Map

## Main Route

### Entrance Hall

- purpose: orient the visitor and establish the museum tone
- current status: implemented

### Room 01 — Origins

- purpose: begin the journey with the Game Boy as the defining portable artifact
- current status: implemented

### Room 02 — Color Evolution

- purpose: show how handheld play became brighter without losing portability
- current status: implemented

### Room 03 — Performance Expansion

- purpose: show how handheld design widened into stronger performance and broader ambition
- current status: implemented

### Room 04 — Multimedia Era

- purpose: show the moment handhelds pursued a broader media identity
- current status: implemented

### Room 05 — Innovation Era

- purpose: show how interface experimentation and depth reshaped the portable journey
- current status: implemented

### Room 06 — Modern Era

- purpose: show how the border between handheld and home play dissolved
- current status: implemented

## Rule

Each room should teach one clear historical or design contrast rather than
trying to summarize all portable gaming history at once.
