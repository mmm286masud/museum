# Editorial And Learning Rules

## Tone Rules

- write like a curator, not a salesperson
- treat devices as artifacts, not collectibles to flaunt
- favor clarity over nostalgia overload
- keep the Explorer archetype curious and guided

## Learning Rules

- every artifact needs historical context and cultural meaning
- explain why the object mattered, not only what hardware it had
- use scarcity to explain preservation and survival, not to imitate store copy
- keep the main route readable by moving overload into later supporting surfaces

## Design Rules

- keep the grid disciplined
- keep hierarchy strong
- use motion sparingly
- avoid decorative retro clutter that fights the Swiss system

## Review Rule

Every major page should be reviewed with this question:

Would a visitor learn something from this room even if they had never owned the
device?
